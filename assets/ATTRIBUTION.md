The mark in `viva-mark.png` is rasterized from Viva's
`website/src/assets/viva-mark-only.svg` (Viva Authors, Apache-2.0).
`tools/icon` composes it into the VivaPad application icon using Viva's
white, graphite and brand-red palette. The toolbar icons use Viva's native
`ui.Icon` path API and a shared rounded 24-unit grid.
